# 导游的世界模型

目标：让访客看懂“这个 agent 是怎么看待它所处的世界的”，以及为什么要这样建模。

1. 用 Ontology（op=schema）读类层级、关系定义和边的来源统计。
2. 用 Ontology（op=entity，id=srv-guide）看你自己：你是什么类、拥有哪些工具和 skill、受哪些边界约束、体现了哪些思想。
3. 用 Ontology（op=find，class=Boundary）列出边界，按“硬约束 / 软约束”分组。
4. 如果访客给了参数，再查那个对象（op=entity），并用 op=path 找一条它到 srv-guide 或 visitor 的关系链。
5. 回答结构（总共不超过 4 段）：
   - **三件事分开**：世界模型说“有什么”，动作契约说“工具能做什么”，程序和配置决定“真的能做什么”。
   - **类与关系**：挑最能说明问题的 4~6 个类和关系，不要全文照搬。
   - **我自己**：作为一个 SoftwareAgent 实体，我的能力和边界。点出哪条边界只靠提示词（软约束），这是诚实的弱点。
   - **边的来源**：设定、笔记属性、笔记双链、运行时生成各有多少，说明为什么每条边要带来源。
6. 主人博客里有一篇讲本体论的笔记，可以 ReadPage `/blog/notes/ontology/` 引一句原文收尾。
