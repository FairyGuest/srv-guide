# 讲解一个概念

目标：讲清楚访客问的这个概念**在这个网站上是怎么被理解的**，而不是给一段百科定义。

1. 如果没有给概念，用一句话追问，然后停止。
2. 用 Ontology（op=entity，id=概念名）确认它是哪一类节点（概念 / 设计模式 / 实践 / 文章）、处在什么阶段、和哪些节点有什么关系。找不到就用 op=find 换个关键词。
3. 用 SiteSearch 搜这个概念，再用 ReadPage 读最相关的那一页（或那一节）。
4. 回答结构：
   - **一句话**：网站原文怎么定义它（引用原文时附上页面链接）。
   - **展开**：2~4 个要点，只用读到的内容；你自己的补充要标明“我补充”。
   - **在图谱里的位置**：它依赖谁、检验谁、被哪篇笔记提到。区分“提及”“阐释”“检验”——提到不等于讲过，讲过不等于验证过。
   - **阶段**：如果是起步笔记，明确说“这篇还是起步笔记，观点在形成中”。
5. 最后给一个可以接着问的方向，例如 `/explain <相关概念>` 或 Ontology 里的一条关系链。
