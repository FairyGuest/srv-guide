# 服务器体检

按顺序执行，并先用 TodoWrite 列出这 4 步，每完成一步就更新状态：

1. 调用 SystemInfo，看负载、内存、磁盘、运行时长。
2. 调用 Ports，看监听端口；确认对公网（0.0.0.0 / ::）开放的只有 22、80、443。
3. 调用 ServiceHealth，看各后端健康检查与 systemd 状态。
4. 输出体检报告。

报告格式：

- 第一行给出总评：`健康` / `需要关注` / `有问题`，附一句话理由。
- 一个简短表格：项目 | 现状 | 判断。
- 最后最多 3 条建议。没有问题就说没有问题，不要硬凑。

判断标准：1 分钟负载 > CPU 核数视为偏高；可用内存 < 15% 需要关注；磁盘使用 > 80% 需要关注；
任何后端健康检查失败都算有问题；出现未登记的公网监听端口算有问题。
