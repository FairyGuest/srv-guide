# Agent 工坊路线图

目标：让 agent 在受限权限下接管这台服务器的大部分运维工作。

| 阶段 | 工具 | 状态 |
| --- | --- | --- |
| 0 | srv-guide：只读导游，讲解环境、体检、生成部署方案 | **已上线（就是我）** |
| 1 | 环境分析：扫描项目依赖与资源需求，对照服务器现状出报告 | 规划中 |
| 2 | 自动部署：生成 systemd 单元、Nginx 路由与目录，关键步骤人工确认 | 规划中 |
| 3 | 部署优化：观察日志与资源，提出并应用可回滚的优化 | 规划中 |

设想的工作流：读环境 → 出方案 → 人确认 → 在 deploy 权限内执行 → 回报与持续优化。
权限边界不会放松：agent 不拿 sudo、不碰 Docker socket。
