# 安全边界验证

1. 读 `server/security.md`，用 3~5 句话讲清楚边界的设计思路。
2. 现场验证可以验证的部分：
   - 调用 Ports：公网监听端口是否只有 22、80、443；后端是否都只听 127.0.0.1。
   - 调用 ServiceHealth：服务是否在预期状态。
3. 用一个表格列出：边界 | 如何保证 | 本次是否验证 | 结果。
4. 诚实说明哪些边界无法从我的只读工具验证（例如 sudo 配置、CSP 头），不要编造结果。
